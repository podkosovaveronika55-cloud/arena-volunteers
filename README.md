# Рейтинг волонтёров G-Drive Арены

Сайт использует сохранённые данные Google Таблицы. GitHub Actions раз в сутки загружает таблицу, сохраняет снимок и публикует сайт. Запланированное время — 06:17 по Омску (00:17 UTC), но GitHub может задержать или пропустить запуск. На сайте показано фактическое время обновления; если прошло более 48 часов, появится предупреждение. Таблица должна быть доступна для просмотра всем, у кого есть ссылка.

## Публикация на GitHub Pages
1. Распакуйте архив и загрузите **все файлы, включая скрытую папку `.github/workflows`**, в корень репозитория GitHub. Ветка должна называться `main`. Удобнее загрузить через git: веб-интерфейс может не показывать скрытые папки.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
3. Проверьте, что Actions разрешены, и в **Settings → Actions → General → Workflow permissions** разрешена запись в репозиторий (Read and write permissions). На некоторых тарифах и в организациях могут действовать другие ограничения.
4. Во вкладке **Actions** выберите «Обновление и публикация рейтинга» → **Run workflow**. Также процесс запускается при изменениях в `main`. После завершения адрес сайта появится в Settings → Pages.
5. Если запуск завершился ошибкой, посмотрите журнал во вкладке Actions. Существующий опубликованный сайт останется с прежними данными; время последнего обновления отображается на сайте. Доступ к таблице и права Actions обязательны.

## Добавление месяца
Сейчас подключён ноябрь 2026 — первый лист таблицы. Другие листы автоматически не обнаруживаются. Для нового месяца создайте отдельную вкладку с той же структурой: ФИО в B, часы мероприятий в C:Q. Добавьте запись в `months.json`, например:

```json
{"key":"2026-12", "label":"Декабрь 2026", "gid":"123456789"}
```

Замените `123456789` на настоящий `gid` из адреса вкладки (`#gid=...`). Между элементами массива нужна запятая. После изменения файла запустится обновление; можно также нажать Run workflow вручную. Общий рейтинг суммирует подключённые месяцы по полному ФИО. Важно одинаковое написание имён. Дубли ФИО на одном листе суммируются.

## Как считаются часы
Сайт складывает числовые значения C:Q и игнорирует R и последующие столбцы, чтобы не прибавлять итог повторно. Пустые и нечисловые ячейки не учитываются. Если появятся мероприятия за пределами C:Q или структура изменится, обновите функцию `parse` в `app.js`. При равных часах место одинаковое; следующее место идёт с пропуском.

При ошибке загрузки хотя бы одного месяца публикация прерывается, чтобы не показывать неполные данные как свежие. Рейтинг учитывается при записи на концерты, но не гарантирует попадание.

ФИО и часы на публичном сайте видны всем. Перед публикацией убедитесь в наличии оснований и согласий на публикацию персональных данных, а также прав на использование фотографии. Сайт не связан с официальными сервисами арены.
